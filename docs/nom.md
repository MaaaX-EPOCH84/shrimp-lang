# Le nom

**Shrimp.** Choisi le 2026-10-20.

## Pourquoi

- Rust aime les crustacés (Ferris est un crabe, ses usagers des
  Rustacés) ; Shrimp reste dans la famille sans la singer.
- *Jumbo shrimp*, l'oxymore favori de George Carlin : un noyau
  minuscule, une bibliothèque énorme. L'architecture en deux mots.
- Shrimp, c'est Rust après *shrink* : Rust rétréci.
- Bubba, dans *Forrest Gump*, récitant toutes les façons de cuisiner la
  crevette : la bibliothèque standard, rangée par thèmes.
- Une syllabe, même prononciation des deux côtés de l'Atlantique,
  /ʃrɪmp/ ; le pluriel reste *shrimp*.
- Le bagage : *shrimp* désigne aussi un avorton. Pour un langage qui
  revendique d'être petit, c'est une force, à condition de le dire avant
  les autres.

## Les trois niveaux

| Usage | Forme |
|---|---|
| Le langage, dans une phrase, la doc, la mascotte | **Shrimp** |
| Organisation GitHub/GitLab, domaine | `shrimp-lang` (à la `rust-lang`) |
| Mot de recherche, hashtag | `shrimplang` (à la `golang` : « shrimp » seul renvoie des recettes) |

Jamais « ShrimpLang » comme nom du langage : personne n'écrit « RustLang ».

Outil : `shrimp`. Extension : `.shr` ou `.shrimp`. Mascotte proposée :
une crevette-mante (frappe la plus rapide du règne animal, yeux les plus
complexes).

## Collisions

Vérifié le 2026-10-20 par une recherche web : aucun langage nommé Shrimp.
Le plus proche est Shrimpl, un petit langage pour débutants avec un
interpréteur en Rust, confidentiel. Le mot est trop commun pour qu'une
recherche soit discriminante : **GitHub, GitLab, crates.io et les noms de
domaine restent à vérifier avant de graver.**

## Écartés

| Nom | Pour | Contre |
|---|---|---|
| Triops | Le plus juste : trois yeux, le compilateur, l'humain, l'IA ; même plan de corps depuis plus de 200 millions d'années ; *shield shrimp* | Moins parlant |
| Prawn | Le plus drôle : Shrimp avec l'accent anglais | Argot britannique (beau corps, tête ratée), insulte australienne, *District 9*, et la bibliothèque Ruby de PDF du même nom |
| Crayfish | « The Cray of fish », pour viser plus vite que le C | Les compilateurs Cray existent |
| Hermit | Habite la meilleure coquille qu'il trouve : l'incubateur dessiné par la nature | `Hermit`, unikernel en Rust |
| Fiddler | Une petite pince et une énorme : noyau et bibliothèque | Le proxy HTTP de Telerik |
| Sea Monkey | « Just add water » : piles incluses | `SeaMonkey` de Mozilla |
| Krill | Ce dont tout l'océan se nourrit | `Krill`, logiciel RPKI |
| Mantis | Frappe et yeux de la crevette-mante | `MantisBT`, gestionnaire d'anomalies |
