# The name

**Shrimp.** Chosen on 2026-10-20.

## Why

- Rust likes crustaceans (Ferris is a crab, its users are Rustaceans);
  Shrimp stays in the family without aping it.
- *Jumbo shrimp*, George Carlin's favorite oxymoron: a tiny core
  language, a huge library. The architecture in two words.
- Shrimp is Rust after a *shrink*: Rust shrunk down.
- Bubba, in *Forrest Gump*, reciting every way to cook shrimp: the
  standard library, arranged by theme.
- One syllable, same pronunciation on both sides of the Atlantic,
  /ʃrɪmp/; the plural stays *shrimp*.
- The baggage: *shrimp* also means a runt. For a language that claims to
  be small, that is a strength, provided we say it before others do.

## The three levels

| Use | Form |
|---|---|
| The language, in a sentence, the docs, the mascot | **Shrimp** |
| GitHub/GitLab organization, domain | `shrimp-lang` (like `rust-lang`) |
| Search word, hashtag | `shrimplang` (like `golang`: "shrimp" alone returns recipes) |

Never "ShrimpLang" as the name of the language: nobody writes "RustLang".

Tool: `shrimp`. Extension: `.shr`. Mascot: a mantis shrimp (the fastest
strike in the animal kingdom, the most complex eyes), drawn by MaaaX in
`assets/`. Fixed at point 1.5, `docs/tool.md`.

## Collisions

Checked on 2026-10-20 by a web search: no language named Shrimp. The
closest is Shrimpl, a small language for beginners with an interpreter
in Rust, little known. The word is too common for a search to be
discriminating, so the registries and the domains were checked one by
one on 2026-10-23, read-only, against the live APIs (crates.io, PyPI,
npm, GitLab, GitHub, RDAP for the domains, Open VSX and the VS Code
Marketplace). Nothing was registered or bought.

| Where | `shrimp` | `shrimp-lang` |
|---|---|---|
| GitHub organization | — | **Free.** The repository lives under `MaaaX-EPOCH84/shrimp-lang`; the organization is not created |
| GitLab group or user | — | Free |
| crates.io | Taken: `shrimp` 0.0.0, "A simple shell", one placeholder version from 2021-09-23 | Free |
| PyPI | Taken: `shrimp` 0.0, an empty placeholder, no file | **Taken**: `shrimp-lang` 2.0.1, "Shrimp Language Compiler - Native Windows Edition", four releases all on 2026-06-07, author "Shrimp Creator", no repository, no page. A toy language in Java packaged with its runtime (48 MB), `shrimp run <file>`, extension `.srm`. The only homonym that is a language; found nowhere else on the web |
| npm | Taken: `shrimp`, an SDK for a recipe service, 2015-2022 | Free |
| Domains | `shrimplang.org` and `shrimplang.com`: registered 2023-08-18, expire 2027-08-18, parked (empty redirect) | `shrimp-lang.org`, `shrimp-lang.dev`, `shrimp-lang.com`: **not registered** (RDAP: no object) |
| VS Code Marketplace, Open VSX | No extension for a language named Shrimp; `bdt-apex.shrimpl` serves Shrimpl | — |

GitHub repositories named after a Shrimp language exist, all obscure
(zero to two stars): `natesanchez314/shrimp-lang` (2024, Rust),
`elipie/ShrimpLang` (2020), `tedbauer/shrimp` (a Game Boy language,
2026). None has a site, a package or an extension.

**The extension `.shr`** belongs to no programming language. It is used
by `shar` shell archives (an old variant of `.shar`), by Signal Hound
spectrum sweeps, and by a handful of dead formats (CorelSHOW, PC-Shrink,
an Apple II bitmap). None of them is a plausible neighbor in a source
tree.

**Verdict.** Nothing blocks the name. The `shrimp-lang` form is free
everywhere that matters — GitHub organization, GitLab, crates.io, npm,
the three domains — and is the one to use; `shrimp` alone is taken on
every registry by placeholders or unrelated projects, which is why the
organization and the domain carry the suffix. The PyPI homonym is the
only language of the same name; it is a toy without a trace outside its
package, and Shrimp has no reason to be on PyPI. Reservations — the
organization, the domains — are MaaaX's own gesture, outside this
repository.
