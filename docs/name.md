# The name

**Shrimp.** Chosen on 2026-10-20.

## Why

- Rust likes crustaceans (Ferris is a crab, its users are Rustaceans);
  Shrimp stays in the family without aping it.
- *Jumbo shrimp*, George Carlin's favorite oxymoron: a tiny core
  language, a huge library. The architecture in two words.
- Shrimp is Rust after a *shrink*: Rust shrunk down.
- Bubba, in *Forrest Gump*, reciting every way to cook shrimp: the
  standard library, arranged by theme.
- One syllable, same pronunciation on both sides of the Atlantic,
  /ʃrɪmp/; the plural stays *shrimp*.
- The baggage: *shrimp* also means a runt. For a language that claims to
  be small, that is a strength, provided we say it before others do.

## The three levels

| Use | Form |
|---|---|
| The language, in a sentence, the docs, the mascot | **Shrimp** |
| GitHub/GitLab organization, domain | `shrimp-lang` (like `rust-lang`) |
| Search word, hashtag | `shrimplang` (like `golang`: "shrimp" alone returns recipes) |

Never "ShrimpLang" as the name of the language: nobody writes "RustLang".

Tool: `shrimp`. Extension: `.shr` or `.shrimp`. Proposed mascot: a
mantis shrimp (the fastest strike in the animal kingdom, the most
complex eyes).

## Collisions

Checked on 2026-10-20 by a web search: no language named Shrimp. The
closest is Shrimpl, a small language for beginners with an interpreter
in Rust, little known. The word is too common for a search to be
discriminating: **GitHub, GitLab, crates.io and domain names remain to be
checked before carving it in stone.**

## Set aside

| Name | For | Against |
|---|---|---|
| Triops | The most accurate: three eyes, the compiler, the human, the AI; same body plan for over 200 million years; *shield shrimp* | Less evocative |
| Prawn | The funniest: Shrimp with a British accent | British slang (nice body, bad face), Australian insult, *District 9*, and the Ruby PDF library of the same name |
| Crayfish | "The Cray of fish", to aim faster than C | Cray compilers exist |
| Hermit | Lives in the best shell it can find: the incubator as drawn by nature | `Hermit`, a unikernel in Rust |
| Fiddler | One small claw and one huge one: core language and library | Telerik's HTTP proxy |
| Sea Monkey | "Just add water": batteries included | Mozilla's `SeaMonkey` |
| Krill | What the whole ocean feeds on | `Krill`, RPKI software |
| Mantis | The mantis shrimp's strike and eyes | `MantisBT`, the bug tracker |
