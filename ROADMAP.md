## Step 1 — Decisions  [E1]
1.1 ✅ [P1] The non-negotiable guarantees — `docs/guarantees.md`, read and approved by MaaaX on 2026-10-21. Five retained on criterion (mechanically verifiable, forbids something nameable, not deducible from another): G1 no UB outside `unsafe`, G2 lifetimes decided at compile time, G3 no data races, G4 nothing hidden, G5 no forgotten case. Set aside: memory safety (deduced from G1, restated as G2), errors as values (absorbed by G4 and G5), compatibility and bounded spec (governance, 1.2 and 1.3), zero-cost abstraction (forbids nothing). Major decision: no destructor, resources are types to be consumed explicitly (MaaaX's choice against the Rust-style `Drop` proposed first). Ten pairs arbitrated, 23 verdicts, sources re-read except Go 2012
1.2 ✅ [P2] The complexity budget and the non-goals — `docs/budget.md`, read and approved by MaaaX on 2026-10-21. Budget = a grid of seven questions in order (Q0 veto of the guarantees, Q1 library, Q2 a measurement served, Q3 witness program, Q4 one way only, Q5 every interaction settled, Q6 cost in tokens), the first no stops; ceiling in spec tokens to be fixed in 1.3, everything admitted provisionally until then; admitting is irreversible, refusing is reversible, when in doubt refuse. Verdicts: `defer` refused Q4 (doubles the imposed consumption; constraint for step 3: consumption on every path written once, without destructor), `async`/`await` refused Q5 (a cancelled future = a resource not consumed without destructor; `std` doubled), inheritance refused Q5 (open hierarchy against G5, slicing against value semantics), local inference refused Q3 (MaaaX: strict, every type written out, an inferred type is implicit code when reading; the assistant proposed admitted but bounded). Non-goals: four confirmed, UI amended (safe C wrappers per system in `x/`, no common abstraction), amendment carried into requirements §6, dated and signed; no sixth one. Set aside: a ceiling alone without a grid, or a grid without a ceiling. Sources re-read: Go spec and FAQ, Zig reference, Rust std, async book, book, edition guide
1.3 ✅ [P3] The size of the core language spec — `docs/spec_size.md`, read and approved by MaaaX on 2026-10-21. Ceiling: 100,000 tokens all included (the whole of Book I as the AI loads it, core language examples included; edition appendices and the `std` index outside the ceiling), under the worst of four open vocabularies frozen in the repository (o200k_base, cl100k_base, Qwen3, DeepSeek-V3), counted by a single BPE engine written in `tools/tokcount/` (Rust, later Shrimp) — three decisions by MaaaX: several tokenizers and the worst score, a fixed figure rather than a fraction of a window, the whole of Book I. Measured (worst vocabulary): Go 56,519, Zig 117,907, C language alone 144,182, Rust reference 303,578, C++ language alone 380,718, whole C23 601,915, whole C++23 1,617,308; Rust minus what Shrimp refuses: 216,000. Book I = a common trunk always loaded + self-contained sections on demand, ceiling on the whole, split and trunk figure deferred to 1.7. Set aside: a single vocabulary plus a guessed margin, a home-made vocabulary, merging vocabularies, a ceiling as a fraction of a window, 60,000, 150,000, the ceiling/target pair. Evidence: `check/compare.py`, twenty counts identical to tiktoken 0.14.0 and tokenizers 0.23.3, zero discrepancy; `measure.sh` replayed, identical figures; 13 tests, clippy and rustfmt clean. Requirements §2 and §8, budget §3 and `README.md` refer to the document. First code in the repository before step 7: measurement tooling, not the compiler. Not measured: Anthropic's tokenizer
1.4 ✅ [P4] The license — `docs/license.md`, read and approved by MaaaX on 2026-10-22. Dual license MIT or Apache-2.0 at the recipient's option, like Rust; a single license for everything, code, `docs/` and the Bible; holder "2026 MaaaX-EPOCH84 and the Shrimp contributors", no copyright assignment. Four decisions by MaaaX on 2026-10-22 (license, scope, holder, public repository with a warning at the top of `README.md`). GPLv3 set aside: `core` and `std` are linked into every program, a GCC-style runtime exception would be needed (3.1, 2009); also set aside MIT alone, Apache-2.0 alone (incompatible with GPLv2 per the FSF), MPL-2.0, a separate documentation license, a `COPYRIGHT` file. Put in place: `LICENSE-MIT` (SPDX text), `LICENSE-APACHE` (exact copy from apache.org, SHA-256 cfc7749b…), `THIRD_PARTY.md` (four vocabularies), `license` in tokcount's `Cargo.toml`, License section and "under design" banner in `README.md`, common file header on the seven sources (logo, motto, path, role, author, license, SPDX; libretro-cake model, validated by MaaaX). Sources re-read the same day: Rust, book, reference, apache.org, SPDX, GCC exception, FSF list. Found in passing: the test `base64::round_trip_every_length` overflowed in `u8` since 5e54162, fixed; 13 tests pass, clippy and rustfmt clean. Left outside the point: commit, push, switching the repository to public
